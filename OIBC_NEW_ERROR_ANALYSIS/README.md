## Statistical definitions
Error=forecast-actual. ME, MAE, RMSE, median absolute error, population SD, quantiles, sign frequencies, standardized third/fourth moments. Zero-variance skew/kurtosis and correlation are undefined, not fabricated as zero. Normalize by positive installed kW, never actual near-zero generation. All summaries report expected/sample/missing counts and coverage.
Group error=sum(e_i); A=abs(sum e_i), B=sum(abs e_i), cancellation=B-A. Cancellation fraction is missing for B=0. Missing plant forecast/actual makes the full group-hour missing rather than a partial portfolio sum. Comparison refuses incomplete paired coverage instead of silently dropping it.
Correlation and covariance use identical complete within-group hours. Cov(e_i,sum e_j) sums to portfolio variance. mean(e_i*sign(sum e_j)) sums to group MAE; contributions may be negative. Neither is a reassignment recommendation. Pair matrices include sample counts. ACF matches exact lagged timestamps and does not bridge gaps; directional episodes break on missing/zero errors or timestamp gaps.
Paired model MAE differences resample nonoverlapping complete KST calendar-day blocks within each fold/round/group, with 1/7-day sensitivity. The method approximates independence across blocks; 7-day blocks are not proof of independence. Fewer than configured blocks yields unavailable CI. Observed full-period difference and covered-block difference/coverage are separate. No p-values, multiplicity correction, causal claims or automatic winner selection. Many exploratory slices create selection bias.
Weather bins are fixed in config, not fitted on holdout. Only supplied issue-time fields are joined, with issued_at/available_at<=decision_at. Provider disagreement must be supplied only after verifying compatible variables, units and lead times. Missing fields remain unavailable; no external weather.

## Competition relevance
Penalty is 0.1*SMP*k*abs(GROUP signed error), NOT summed plant absolute errors. Missing SMP or unverified peak convention => unavailable penalty files. No synthetic SMP is generated by the runner; only the manually checked test uses prices. Negative SMP preserves signed weighted terms; concentration shares are unavailable when nonnegative-cost interpretation fails. Official timing/multiplier rules still need authoritative documentation; defaults do not certify competition compliance.
